See It In Action

From zero to a running, tested app in 4 commands.

# Create a sandbox with port mapping $ meatloaf create --image node:20-alpine -p 3000:3000 ✔ Sandbox created: sandbox-abc123 # Install dependencies and start the app $ meatloaf exec sandbox-abc123 "npm install && node server.js &" # Test the endpoint $ meatloaf test http://localhost:3000/ GET http://localhost:3000/ → 200 OK (12ms) {"message": "Hello from Meatloaf! 🥩", "status": "running"} # Benchmark it $ meatloaf bench http://localhost:3000/ -n 1000 -c 50 ⚡ 724 req/s | 100% success | P50: 5ms | P95: 26ms # Clean up $ meatloaf destroy sandbox-abc123 ✔ Sandbox destroyed and cleaned up 🧹
