## Tweet 2 (The Solution)

Meet Meatloaf 🥩 — an open-source CLI that gives AI agents a body.

```bash
npm install -g meatloaf-cli
```

It lets AI agents:
→ Spin up Docker sandboxes
→ Run commands & scripts
→ Test HTTP endpoints
→ Take screenshots
→ Stream logs & debug
→ Iterate on build→test→fix

---

## Tweet 3 (How It Works)

One command does everything:

```
meatloaf up ./my-app
```

This will:
1. Create a sandbox
2. Upload your files
3. Install dependencies
4. Start the app
5. Wait for it to be ready
6. Report success

The AI agent gets full control. You get working software.
